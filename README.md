# ✨ DailyFlow - All-in-One Life Planner & To-Do Dashboard

Aplikasi web manajemen kehidupan & produktivitas komprehensif dengan tema estetik, wallpaper dinamis resolusi tinggi, audio feedback harmonis, efek konfeti perayaan, dan integrasi jam digital real-time Jakarta (WIB).

---

## 🌟 Fitur Utama

### 1. 🕒 Jam Digital Real-Time Jakarta Indo (WIB)
- Jam digital real-time format `HH:mm:ss WIB` yang sinkron secara presisi.
- Penamaan hari & tanggal lengkap dalam Bahasa Indonesia (contoh: *Minggu, 25 Oktober 2026*).
- Ucapan dinamis kontekstual waktu lokal:
  - 🌅 **Selamat Pagi** (04:00 - 10:59)
  - ☀️ **Selamat Siang** (11:00 - 14:59)
  - 🌇 **Selamat Sore** (15:00 - 18:29)
  - 🌙 **Selamat Malam** (18:30 - 03:59)
- Banner kutipan inspiratif harian (*Daily Motivational Quotes*) dengan tombol acak kutipan baru.

### 2. ✅ To-Do List Harian (Full CRUD)
- **Create**: Tambah tugas baru dengan judul, kategori, tingkat prioritas (🔴 Tinggi, 🟡 Sedang, 🟢 Rendah), batas tanggal, dan jam target (WIB).
- **Read**: Tampilan modern dengan ringkasan persentase progres harian dan visual status bar.
- **Update**: Edit tugas kapan saja & centang selesai dengan efek suara harmonis serta perayaan konfeti.
- **Delete**: Hapus tugas individual atau gunakan tombol pembersih *"Bersihkan Selesai"* sekaligus.
- **Filter & Search**: Filter berdasarkan status (Semua, Belum, Selesai), tingkat prioritas, kategori tag, dan pencarian instan.

### 3. 🗓️ Life & Planning Hub (3-in-1 System)
- **⏰ Daily Planner / Schedule (Time-Blocking)**:
  - Blok waktu aktivitas dari pagi hingga malam.
  - **Indikator Real-Time**: Otomatis mendeteksi dan memberi highlight pada agenda yang sedang berlangsung di jam saat ini berdasarkan waktu Jakarta (WIB)!
  - CRUD blok waktu lengkap dengan kategori, catatan, dan aksen warna.
- **📅 Weekly Planner (Jadwal 7 Hari)**:
  - Papan grid 7 hari (Senin s/d Minggu) dengan penanda khusus akhir pekan.
  - Tambah, centang, atau kelola agenda per masing-masing hari.
- **🗓️ Monthly Planner (Kalender & Target Bulanan)**:
  - Kalender interaktif lengkap dengan navigasi antar bulan.
  - Klik tanggal berapa saja untuk melihat atau menambahkan agenda dan deadline penting.
  - *Fokus Utama Bulan Ini* (banner komitmen yang dapat diedit).
  - *Prioritas Utama Bulanan* (daftar checklist target utama dengan CRUD).

### 4. 🌅 Morning & Night Routine (Rutinitas Pagi & Malam)
- Pembagian khusus antara ritual pagi ☀️ dan ritual malam 🌙.
- Perhitungan persentase pencapaian masing-masing rutinitas.
- Pelacak *Streak Harian* beruntun (misal: 🔥 7 Hari Beruntun).
- CRUD rutinitas lengkap (nama kebiasaan, jam target WIB, emoji ikon).
- Tombol reset cepat untuk memulai hari baru.
- Efek perayaan fanfare & super-confetti saat seluruh rutinitas terselesaikan!

### 5. 📝 Notes & Memo Estetik
- Tampilan sticky notes bergaya estetik modern dengan palet warna pastel (Kuning Hangat, Mint Segar, Lavender, Soft Rose, Sky Breeze, Violet Dream).
- Fitur **Pin to Top** 📌 untuk menyematkan catatan prioritas di paling atas.
- Tag kategori (Ide, Resep, Buku, Pribadi, Kerja, Kutipan).
- Fitur pencarian instan berdasarkan judul dan isi catatan.
- CRUD catatan lengkap.

### 6. 🎯 Quick Goals (5 Jangka Waktu)
- **Hari Ini (Today)**: Target 24 jam.
- **Minggu Ini (This Week)**: Target mingguan.
- **Bulan Ini (This Month)**: Target 30 hari.
- **Tahun Ini (This Year)**: Target tahunan.
- **Tujuan Hidup (Life Goals / Bucket List)**: Visi jangka panjang.
- Dilengkapi **Milestone Checklist** bertahap (mencentang milestone otomatis memperbarui persentase progres tujuan!).

### 7. 💖 Wellness & Health Tracker
- 💧 **Water Intake Tracker**: Wadah animasi tingkat air, tombol cepat `+250ml (Gelas)`, `+500ml (Botol)`, dan `+1 Liter`.
- 🏋️‍♂️ **Personal Workout Routine (Split 7 Hari & Full CRUD)**:
  - **Senin**: Chest Day 🏋️‍♂️ (Regular push up, diamond push up, wide push up, incline/decline, dips)
  - **Selasa**: Lengan Tangan & Back Punggung 💪 (Pull up, bicep curls, hammer curls, rows, tricep dips)
  - **Rabu**: Perut / Core & Abs 🔥 (Plank, bicycle crunches, leg raises, russian twists, mountain climbers)
  - **Kamis**: Leg Day / Kaki 🦵 (Bodyweight/goblet squats, walking lunges, bulgarian split squats, calf raises, glute bridges)
  - **Jumat**: All Body / Full Body ⚡ (Burpees, push up to renegade row, jump squats, pull ups, plank to push up)
  - **Sabtu**: Rest / Cardio (Lari Santai 5 KM) 🏃‍♂️
  - **Minggu**: Rest / Cardio (Active Recovery & Jalan Santai) 🧘
  - **Fitur Tambahan**: Auto-Highlight hari ini sesuai waktu Jakarta WIB, Rest Timer jeda antar-set (30s, 60s, 90s), dan CRUD latihan (Tambah, Edit fokus/gerakan, Hapus, Reset checklist harian).
- 💧 **Water Intake Tracker**: Wadah animasi tingkat air, tombol cepat `+250ml (Gelas)`, `+500ml (Botol)`, dan `+1 Liter`.
- 😊 **Mood Tracker**: Pilihan suasana hati harian (🥳 Sangat Bahagia, 😊 Bahagia, 😌 Tenang, 🥱 Lelah, 😣 Stres, 😢 Sedih) disertai catatan refleksi.
- 💤 **Sleep Tracker**: Input jam tidur & jam bangun yang otomatis menghitung total durasi jam tidur, rating bintang kualitas tidur, dan catatan bangun tidur.
- 🏃 **Aktivitas Fisik & Langkah**: Penghitung langkah kaki (steps counter) vs target harian, menit workout, tipe olahraga, dan estimasi kalori terbakar.
- 🧘 **Gratitude Journal**: 3 hal yang disyukuri hari ini dengan CRUD.

### 8. 💰 Finance Tracker (Pemasukan & Pengeluaran)
- Kartu ringkasan kas: **Total Saldo Bersih**, **Total Pemasukan**, dan **Total Pengeluaran** dalam format Rupiah (`Rp xxx.xxx`).
- Distribusi pengeluaran per kategori dengan diagram batang persentase.
- Riwayat transaksi dengan filter tipe (Pemasukan/Pengeluaran), kategori, serta kata kunci pencarian.
- CRUD pencatatan transaksi lengkap.

### 9. 🎨 Tema Estetik & Kustomisasi Wallpaper Dinamis
- 6 Tema Estetik Pilihan:
  1. 🌿 **Ghibli Fantasy**: Suasana alam & pedesaan anime yang menenangkan.
  2. ☕ **Cozy Lo-Fi Study**: Suasana hangat kafe kopi dan rintik hujan.
  3. ⚡ **Neon Cyberpunk**: Gemerlap kota masa depan bernuansa fuchsia & neon.
  4. 🌸 **Pastel Sakura**: Kelembutan senja bunga sakura Jepang.
  5. 🌙 **Midnight Obsidian**: Elegan, gelap, dan langit berbintang malam.
  6. 🌊 **Deep Ocean Chill**: Kesegaran biru laut dan samudera luas.
- Slider pengatur tingkat kegelapan (*Dimming Opacity*) dan efek buram (*Blur Intensity*).

### 10. 💾 Penyimpanan & Pencadangan Data
- Tersimpan otomatis secara persisten di peramban pengguna (*LocalStorage*).
- **Ekspor Cadangan**: Unduh seluruh data ke berkas JSON dengan 1 klik.
- **Impor Cadangan**: Pulihkan data dari berkas JSON kapan saja.
- **Reset Data Demo**: Kembalikan data contoh awal yang lengkap dan berbahasa Indonesia.

## 📦 Build Produksi & Install ke HP (PWA / APK)

### A. Build produksi

```bash
npm run build
```

Hasil build ada di folder `dist/`. Folder ini berisi aplikasi lengkap (HTML, JS, CSS, `manifest.json`, `sw.js`, dan ikon PWA).

### B. Install sebagai PWA (tanpa file APK — paling cepat)

1. Host folder `dist/` ke URL HTTPS. Cara termudah: buka **https://app.netlify.com/drop** lalu seret folder `dist/` (atau file `dailyflow-pwa.zip`). Netlify akan memberi URL publik.
2. Buka URL tersebut di **Chrome Android**.
3. Ketuk menu **⋮ (titik tiga) → "Add to Home screen" / "Install app"**.
4. Aplikasi terpasang di layar utama, berjalan **fullscreen**, **offline**, dan **data tersimpan di HP** (LocalStorage).

> Pastikan hosting melayani dari **root domain** (`/`), bukan subpath seperti `/repo/`, karena aplikasi ini memakai path absolut (`/manifest.json`, `/sw.js`, `/assets/...`). Netlify/Vercel melayani dari root — aman.

### C. Buat file APK Android (TWA) — tanpa Android SDK di PC

1. Host `dist/` ke URL HTTPS (langkah B.1 di atas).
2. Buka **https://www.pwabuilder.com**.
3. Masukkan URL aplikasi → klik **Start**.
4. Pilih **Android** → **Package for stores** (atau **Download APK**).
5. PWABuilder akan menghasilkan **file `.apk`** yang siap di-install ke HP (plus key untuk update berikutnya).

> Aplikasi hasil TWA tetap membaca data dari LocalStorage HP dan bekerja **offline** karena Service Worker sudah meng-cache seluruh aset (`public/sw.js`).

### D. (Alternatif) Build APK lokal dengan Capacitor

Membutuhkan **JDK 17+** dan **Android SDK**. Setelah terpasang:

```bash
npm i -D @capacitor/cli @capacitor/core @capacitor/android
npx cap init DailyFlow id.dailyflow.app --web-dir=dist
npx cap add android
npx cap sync
npx cap open android   # lalu Build APK dari Android Studio
```
